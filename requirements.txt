# Notable constraints for this project:
#   - anthropic/openai SDKs: a major bump historically changes the client
#     constructor and response shape (e.g. anthropic 0.x → 1.x moves

#     touches both — break either and Level 0-3 demos all stop working.
#   - streamlit: cache_resource / session_state semantics drift across
#     major versions; the app uses @st.cache_resource with explicit key
#     isolation (H2 fix) so we need to ride 1.x.
#   - pandas: used only for CSV/analytics in notebooks — safe range.
